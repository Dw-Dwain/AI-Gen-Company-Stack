# Design Gates

## Build Gates

- Structure: Does the page shape fit the product, or is it the common AI landing page rhythm?
- Type: Are display, body, and label roles distinct?
- Color: Is the accent controlled and meaningful?
- Space: Are spacing values on a consistent scale?
- Hierarchy: Can the eye rank the page in two seconds?
- Evidence: Does the UI show the real product, object, data, or workflow?
- Restraint: Did decorative elements earn their place?
- Responsiveness: Does every text block fit on mobile and desktop?

## Domain Bias

| Domain | Bias |
|---|---|
| SaaS/dashboard | Dense, quiet, scannable, operational |
| Creative/writing | Editorial, typographic, artifact-led |
| Security | High contrast, evidence-led, calm severity |
| Developer tool | Precise, terminal/docs influence, low decoration |
| Consumer app | Object-led, tactile, clear action path |
