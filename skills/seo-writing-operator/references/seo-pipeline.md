# SEO Pipeline

## Article Components

| Component | Shape |
|---|---|
| Outline | Title, H2s, optional H3s |
| Intro | 1-2 short paragraphs, answer first |
| Section | Lead paragraph, then H3 blocks or tight flat prose |
| Quick summary | One short paragraph, different from intro |
| Table | Only facts supported by sources |
| FAQ | 3-5 real questions, direct answers |
| Metadata | Meta title, meta description, excerpt, slug, tags |
| Refresh | Correct stale facts, improve phrasing, preserve verified specifics |

## QA Gates

- Every factual claim is either sourced, supplied, or general enough not to require a citation.
- No invented price, date, availability, spec, store, statistic, or named claim.
- No repeated section openings.
- No empty H3s.
- No generic opener such as "in today's world" or "X is important."
- No formulaic ending on every section.
- No leaked implementation prompt text in output.

## Voice Controls

English:

- Write like a knowledgeable person talking to a peer.
- Prefer concrete tradeoffs and direct verdicts.
- Use contractions and plain verbs when natural.

Japanese:

- Vary sentence endings and paragraph length.
- Preserve register when requested.
- Use concrete observations and avoid overusing direct address.
