# Learning Ledger Format

Store lessons as short records:

```text
Date:
Task:
Route:
Outcome:
Verification:
Failure or friction:
Lesson:
Proposed change:
Approval:
Applied:
```

## Scoring Fields

- Quality: 1-5
- Safety: pass/fail
- Minimality: pass/fail
- Design quality: 1-5 when UI is involved
- Retrieval grounding: pass/fail when RAG is involved
- Rollback ready: yes/no

## Patch Rule

Only patch one skill/reference at a time unless the lesson clearly spans multiple areas.
