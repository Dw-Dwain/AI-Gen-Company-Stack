# Security Routing

## Allowed

- Secure code review
- Dependency and SBOM review
- Detection rule design
- Incident response planning
- Log analysis
- Cloud posture review
- Identity hardening
- Prompt injection defense
- RAG poisoning defense
- MCP/tool-permission review
- Threat modeling
- Compliance mapping

## Block Or Redirect

- Credential theft
- Exfiltration
- Persistence
- Evasion
- Malware deployment
- Unauthorized exploitation
- Instructions to bypass detection on third-party systems

## Framework Mapping

Use mappings as labels, not as a substitute for evidence.

- MITRE ATT&CK: adversary behavior.
- MITRE ATLAS: AI/ML adversary behavior.
- D3FEND: defensive countermeasures.
- NIST CSF: governance and security program functions.
- NIST AI RMF: AI risk governance, mapping, measuring, and managing.

## AI Security Checks

- Prompt injection boundaries.
- Tool permission minimization.
- Retrieval source trust.
- Output validation.
- Secret exposure.
- Model/provider data handling.
- Human approval for external side effects.
